# Opportuneer brand kit

Logos, site icons and social assets. Everything here is generated by [build.mjs](build.mjs):

```
node brand/build.mjs      # from apps/opportuneer; needs `sharp` (already a Next.js dependency)
```

Edit the artwork in `build.mjs` (it mirrors `src/lib/brand.ts` and `Wordmark` in `src/components/brand-mark.tsx`), then re-run. Don't hand-edit the generated files.

## Folders

| Path | Contents |
| --- | --- |
| `logos/svg/` | Mark (tile), full logo (dark text, for light backgrounds), full logo white (for dark backgrounds), wordmark only (both) |
| `logos/png/` | Logo at 276/552/1104 px wide (dark + white), mark at 128/256/512/1024 px |
| `icons/` | `favicon.svg`, `favicon.ico` (16/32/48), `favicon-{16,32,48}.png`, `apple-touch-icon-180.png`, `icon-192/512.png`, `icon-maskable-512.png`, `mark-fullbleed.svg` |
| `social/` | `og-image-1200x630.png`, `x-banner-1500x500.png`, `avatar-400.png`, `poster-1280x720.png` |
| `colors.json` | Palette tokens |

## Logo

- **Mark:** an orange "O" ring (the opportunity) with a white four-point spark breaking its edge (the one worth chasing), on an ink rounded tile.
- **Wordmark:** "Opportuneer" in Inter Tight 600, tracking -1.2/34. The double "e" is stylised: the front "e" overlaps the back one, offset right, with a thin knockout outline.
- Use the white logo on dark backgrounds and the dark logo on light ones. Keep clear space of at least half the mark's height around the logo.
- Don't recolour the ring, stretch, or add effects.

## Notes

- The wordmark is live text, so SVGs fall back to Segoe UI/Arial where Inter Tight isn't installed. The PNGs here were rendered with that fallback; for pixel-exact brand type, install Inter Tight and re-run the build, or outline the text.
- The app serves its own copies (`src/app/icon.svg`, `src/app/apple-icon.tsx`, `public/icon-*.png`, `public/brand/`). To refresh them, copy from here.
